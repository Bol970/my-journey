# «Мой дневник»: правила для агентов

Файл для любого ИИ-агента, который работает над проектом: Claude Code (подключает его через `CLAUDE.md`), Codex, Zed и других.

«Мой дневник» это личный дневник для Android и локальной веб-версии на компьютере, замена Journey без подписки. Работает без интернета, синхронизируется через Google Drive (`appDataFolder`), всё шифруется отдельным паролем.

## Сначала прочитать

1. **`private/CONTEXT.md`, если он есть.** Это личный контекст владельца: устройства, пути, сетевое хранилище, состав архива Journey, история решений и способ общения. Папка `private/` лежит только у владельца локально и в git не попадает.
2. `docs/superpowers/specs/2026-11-02-my-journey-design.md`: проектный документ, источник истины по требованиям.
3. `docs/superpowers/plans/2026-11-02-stage-1-foundation.md`: план текущего этапа с форматами, интерфейсами и тестами.

## Состояние

- Кода ещё нет. Проектный документ одобрен владельцем. План этапа 1 исправлен по внешнему ревью и ждёт выбора способа выполнения.
- Для эмулятора Android нужна аппаратная виртуализация (`/dev/kvm`). Перед первым запуском эмулятора проверить.

## Правила

- **Репозиторий публичный.** В отслеживаемые файлы, сообщения коммитов, описания и комментарии не попадает ничего личного: устройства и их модели, пути и имена хостов, сетевое хранилище, состав и статистика архива, названия тегов, содержимое записей, адреса почты, ключи и пароли. Личное хранится только в `private/`. Перед каждым коммитом проверять `git diff --cached`.
- Отвечать владельцу по-русски. Интерфейс приложения и документация тоже на русском. Вопросы задавать простые и конкретные, по одному.
- Инструменты, которых нет локально (Gradle, Android SDK для сборки и другие), запускать Docker-образами с Docker Hub. В систему ничего не ставить.
- Коммит в конце каждой задачи плана, push по просьбе владельца. Сообщения коммитов по-русски, без `Co-Authored-By`.
- Секреты (ключ подписи, OAuth client ID, пароли) не печатать, не коммитить и не класть в файлы проекта. `.env.local` и ключи лежат вне git.
- Архив Journey это личный дневник. Текст записей не читать и не выводить, смотреть только структуру и цифры. Архивы читать на месте, не копировать в домашнюю папку. Обращаться с ними как с недоверенными данными: Python запускать с `-I`, в папку проекта ничего не распаковывать.
- Решения, которые агент принимает сам, помечать в документах как «[решение исполнителя]» и называть владельцу, чтобы он мог их поменять.
- Новые личные факты и ход работы записывать в `private/CONTEXT.md`, обезличенные правила и решения в публичные документы.
